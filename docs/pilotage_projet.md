## 3. Suivi du projet

Le projet est suivi à partir de plusieurs indicateurs  :

- avancement des livrables 
- validation des contrôles qualité 
- reproductibilité du pipeline 
- cohérence des KPI 
- état d'avancement de Tableau et Streamlit 
- préparation de la soutenance

Git et GitHub permettent également de suivre les différentes évolutions du projet.



## 4. Principaux risques

 Problèmes de qualité des données - Audit et contrôles avant analyse 
 Mauvaise interprétation des annulations - Règles métier documentées 
 Complexité technique excessive - Architecture volontairement simple
