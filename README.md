# Customer Value Radar

Projet data Bloc 6 CDSD.

Customer Value Radar est une étude de cas e-commerce basée sur le dataset Online Retail II.

## Objectif

Analyser les données transactionnelles afin de mieux comprendre :

- la performance commerciale ;
- le comportement des clients ;
- la création de valeur client.

## Stack

- Python
- Pandas
- DuckDB
- SQL
- Tableau
- Streamlit
- Git / GitHub
